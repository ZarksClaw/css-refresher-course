# CSS Refresher Course

Interactive Q&A refresher course for CSS developers. 11 chapters covering CSS basics through modern layout and features. No build tools or dependencies — just open `index.html` in a browser.

## Course Content

| # | Chapter |
|---|---------|
| 1 | CSS Basics |
| 2 | Box Model |
| 3 | Colors & Typography |
| 4 | Display & Position |
| 5 | Flexbox |
| 6 | CSS Grid |
| 7 | Responsive Design |
| 8 | Transitions & Animations |
| 9 | Pseudo-classes & Pseudo-elements |
| 10 | CSS Variables & Functions |
| 11 | Modern CSS |

## How to Use

Open `index.html` in any browser, or serve locally:

```bash
python3 -m http.server 8080
```
